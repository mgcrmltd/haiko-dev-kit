# workspace

One folder per app, written by the skills and kept on your machine (git-ignored):

| File | Written by | What it is |
|---|---|---|
| `crm-profile.md` | CRM analysis | your CRM as it matters to the app: entities, lookups to contact, processes, journeys |
| `decisions.md` | every skill | what you chose and why |
| `app-definition.json` | app builder | the app as last pulled from or saved to Studio |
| `security-manifest.json` | security | the manifest as last saved to Studio as a draft |
| `metadata/` | `scripts/crm.py` | raw metadata the analysis read |
